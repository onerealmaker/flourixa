# flourixatech.com

Corporate website for Flourixa Technologies Inc., Calgary, Alberta.

A static site with no build step. All pages (Home, About, Products, Contact, Privacy Policy) are in `public/index.html`.

## Deploying on Render

- Service type: **Static Site**
- Build command: *(leave empty)*
- Publish directory: `public`
- Custom domain: `flourixatech.com` (add under Settings → Custom Domains)
